# ARPAS
(Remotely piloted  aircraft system) es el sistema de aeronave pilotada a distancia  
# RC
(remote control) es el control remoto utilizado por el piloto para manejar un dron
# VLOS
(visual line of sight) el piloto mantiene contacto visual directo con el dron durante el vuelo
# EVLOS
(extended visual line of sight) Es un tipo de operación con drones donde el piloto no ve el aparato directamente, pero utiliza observadores visuales situados en puntos estratégicos que mantienen el contacto visual y avisan al piloto por radio
# BVLOS
(beyond visual line of sight) operaciones de drones donde el piloto maneja el aparato a una distancia o detrás de obstáculos de tal forma que ya no puede verlo de manera directa con sus propios ojos
# NOTAM
(notice to air missions)  cumple una función doble y vital: sirve para avisar al resto de la aviación (helicópteros, aviones) que hay un dron operando en una zona específica, y obliga al piloto del dron a consultar si existen restricciones activas en su ruta
# A.B.C.D.E
- VFR significa Reglas de Vuelo Visual (Visual Flight Rules) 
- IFR significa Reglas de Vuelo por Instrumentos (Instrument Flight Rules)
A-> solo IFR
B-> IFR + VFR, controlados
C-> IFR + VFR, controlados
D-> IFR + VFR, controlados
E-> prinsipalmente IFR controlado

# OACI
(Organización de Aviación Civil Internacional) establece las guías y modelos de regulación para integrar los vehículos no tripulados de forma segura en el espacio aéreo común
